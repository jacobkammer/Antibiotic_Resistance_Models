# Antibiotic_Resistance_Models

Simulation code for the manuscript

> J. W. Kammer, K. Udekwu, and E. A. Hernandez-Vargas,
> **"Virtual Clinical Trial Design for Infective Endocarditis: Evaluating
> Antibiotic Therapy."** (manuscript in preparation)

The model is a dual-compartment pharmacokinetic/pharmacodynamic (PK/PD) model
of methicillin-resistant *Staphylococcus aureus* (MRSA) endocarditis arising
from a bone (osteomyelitis) reservoir. It tracks vancomycin-sensitive and
vancomycin-resistant MRSA in blood and in the bone reservoir that seeds the
blood, through vancomycin therapy, a switch to linezolid, and an
antibiotic-free follow-up period. Populations that fall below a limit of
detection of 10 CFU/mL are treated as extinct.

Monte Carlo cohorts of 1,000 simulated patients sample linezolid potency
(EC50,L), linezolid maximum effect (Emax,L), and the immune clearance rate
(k_immune) from log-normal distributions, and Brent's method locates the
parameter value at which the outcome switches from cleared bacteremia to
relapse.

## Repository layout

All code for the manuscript is in **`Bacteremia Simulation/`**. The other
top-level folders (`old_models/`, `No-Clinical-Resolution/`,
`Non-Linear immune response/`, `Model_Notes.ipynb`) are earlier exploratory
work and are not needed to reproduce the paper.

| File | Purpose |
|---|---|
| `parameters.py` | Single source of truth for all model parameters, sampling distributions, random seeds, and figure provenance |
| `model_Bacteremia.py` | PK, immune response, and the ODE right-hand side |
| `solver.py` | Hybrid ODE integration with a hard limit-of-detection (extinction) boundary |
| `MC_ec50_lzd.py` | Monte Carlo cohort sampling EC50,L |
| `MC_emax_lzd.py` | Monte Carlo cohort sampling Emax,L |
| `MC_immune_response.py` | Monte Carlo cohort sampling k_immune |
| `study_summary_figures.py` | Cross-parameter summary figures (reruns the three cohorts) |
| `EC50_lzd_threshold_sweep.py`, `Emax_lzd_threshold_sweep.py`, `ImmuneResponse_threshold_sweep.py` | Deterministic one-parameter sweeps locating each transition point |
| `test_solver_convergence.py` | Regression tests for solver convergence and extinction behaviour |
| `figure_provenance.tsv` | Records which script and parameter set produced each figure |
| `mrsa_endocarditis_ieee.tex`, `references.bib` | Manuscript source |

`event_location_demo.py`, `SIR_event_detection.py`,
`damped_oscillator_event_detection.py` and `root_finding.py` are small
teaching examples of ODE event detection and Brent's method; they are not
used by the analyses.

## Requirements

- Python 3.12 (tested with 3.12.10)
- NumPy, SciPy, Matplotlib (tested versions are pinned in `requirements.txt`)

```bash
git clone https://github.com/jacobkammer/Antibiotic_Resistance_Models.git
cd Antibiotic_Resistance_Models
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Reproducing the results

Run the scripts from inside `Bacteremia Simulation/`; figures are written to
`Bacteremia Simulation/figures/`, which is created if it does not exist.

```bash
cd "Bacteremia Simulation"

# Monte Carlo cohorts (Results: EC50,L, Emax,L and k_immune)
python MC_ec50_lzd.py
python MC_emax_lzd.py
python MC_immune_response.py

# Cross-parameter summary figures
python study_summary_figures.py

# Deterministic threshold sweeps
python EC50_lzd_threshold_sweep.py
python Emax_lzd_threshold_sweep.py
python ImmuneResponse_threshold_sweep.py
```

| Manuscript figure file | Generated by |
|---|---|
| `mc_ec50_lzd_sweep_kinetics.png`, `mc_ec50_lzd_switch.png` | `MC_ec50_lzd.py` |
| `mc_emax_lzd_sweep_kinetics.png`, `mc_emax_lzd_switch.png` | `MC_emax_lzd.py` |
| `mc_immune_response.png`, `mc_immune_response_switch.png` | `MC_immune_response.py` |
| `distribution_to_switch_ec50.png`, `distribution_to_switch_emax.png`, `distribution_to_switch_immune.png`, `relapse_time_curve.png` | `study_summary_figures.py` |
| `PK_Model.png` | Model schematic (drawn by hand, not generated) |

Each Monte Carlo script prints its outcome split (the percentage of simulated
patients whose bacteremia relapses), the values quoted in the manuscript.

**Reproducibility.** Every random draw uses a fixed seed from
`RNG_SEEDS` in `parameters.py`, so reruns give identical cohorts. Each saved
figure is stamped in `figure_provenance.tsv` with a hash of the parameter set;
to list figures that are out of date with the current parameters, run

```bash
python parameters.py --check
```

**Tests.**

```bash
python -m unittest test_solver_convergence
```
